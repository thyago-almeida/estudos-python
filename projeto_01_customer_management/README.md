# Customer Management System

A command-line customer management system developed in Python.

## Features

- Add customers
- Prevent duplicate customers
- Display registered customers
- Search customers
- Remove customers
- Case-insensitive customer searches
- Prevent empty customer names
- Validate menu input
- Handle invalid menu entries
- Save customers to a text file
- Load customers from a text file
- Persistent customer data

## Python Concepts Practiced

- Lists
- Functions
- `if / elif / else`
- `for` loops
- `while` loops
- `break`
- `continue`
- Boolean flags
- String methods
- `.lower()`
- `.strip()`
- `enumerate()`
- `append()`
- `remove()`
- `try / except`
- File handling
- `with open()`
- Reading and writing files
